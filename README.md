# WhatNext? — Indian Student Career Path Explorer

A completely offline, data-driven React web application that helps Indian students map subject combinations to future careers and higher education pathways.

## Features
- **3-Step Navigator**: Choose your level (School, Undergrad, Postgrad) and select subjects to see matching careers.
- **Match Engine**: Uses Jaccard similarity algorithms to score and recommend pathways.
- **Reverse Lookup**: Search for a career to find the required subject combination.
- **Save & Compare**: Save combinations locally to compare architectural academic journeys.
- **Visual Design**: Premium dark mode UI built strictly with Tailwind CSS and CSS art (no external images).

## Tech Stack
- React 18
- React Router v6
- Vite
- Tailwind CSS v3

## How to Run
```bash
npm install
npm run dev
```
Then open http://localhost:5173 in your browser.
